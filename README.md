# Employee Management System

## Project Description

A Django-based Employee Management System that allows an administrator to manage employee records.

## Features

- Admin Login and Logout
- Employee Dashboard
- Add Employee
- View Employee List
- View Employee Details
- Update Employee
- Delete Employee
- Search Employees by Name or Employee ID
- Form Validation
- Employee Statistics
- Django Admin Panel

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap
